# FlawMatch — бот знакомств по недостаткам

Идея: пользователи матчатся не по достоинствам, а по совместимости слабых сторон —
"взаимодополняемость + толерантность". Каждый указывает свои недостатки и то,
какие недостатки партнёра готов терпеть. Скор совместимости — насколько
недостатки одного человека покрываются толерантностью другого, с обеих сторон.

## Запуск

1. Получите токен бота у [@BotFather](https://t.me/BotFather)
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и вставьте токен:
   ```
   cp .env.example .env
   ```
4. Запустите:
   ```
   python bot.py
   ```

База данных SQLite (`flawmatch.db`) создастся автоматически при первом запуске.


## Как работает алгоритм совместимости

```
coverage_A = доля недостатков A, которые Б готов терпеть
coverage_B = доля недостатков Б, которые A готов терпеть
score = (coverage_A + coverage_B) / 2
```

Пороги настраиваются в `config.py`:
- `MIN_COMPAT_THRESHOLD` — ниже этого анкета вообще не показывается (по умолчанию 34%)
- `GOOD_COMPAT_THRESHOLD` — выше этого показывается бейдж "Отличная совместимость" (65%)

## Что стоит доработать перед продакшеном

- **Хранение фото**: сейчас используется `file_id` Telegram — работает, но зависит
  от того, что бот не удалён и файл не "протух" (Telegram иногда инвалидирует старые id).
- **База данных**: SQLite отлично подходит для MVP и тестов, но при росте нагрузки
  стоит перейти на PostgreSQL + асинхронный драйвер (asyncpg / SQLAlchemy async).
  Синхронные вызовы sqlite3 в текущем виде блокируют event loop на доли секунды —
  для нескольких сотен активных пользователей это не критично, для тысяч — уже стоит поменять.
- **Модерация анкет и фото** (ручная или через API), жалобы/бан.
- **Пагинация/повторный показ**: сейчас "пропущенные" анкеты не показываются повторно —
  возможно, стоит дать опцию "посмотреть ещё раз тех, кого пропустил".
- **Редактирование анкеты** после заполнения (сейчас можно только создать один раз).
- **Геолокация** вместо текстового поля "город", если нужен подбор по расстоянию.
